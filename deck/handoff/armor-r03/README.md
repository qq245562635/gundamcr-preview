# armor-r03：r02 风格的状态重组依据（待界面评审）

本包补充 S01a、S01b、S02、S03，以需求第 13 节为依据。**依赖同级 `armor-r02/`，请同时保留两个目录**。r02 底板、卡框、图窗、原始按钮和纹理未复制或改色，直接按相对路径引用。

## 文件

| 文件 | 用途 |
|---|---|
| `scenes.json` | 十个场景的实际节点、素材引用、卡牌 ID、位置、文字、遮罩、按钮点击框、弹窗来源、互换路径和时长 |
| `sprites/` | 从 r02 材质九宫格重组的空白面板 / 按钮，以及通用白色线性图标；尺寸和 border 在 JSON 的 assets 数组 |
| `fonts/` | 同源 Noto Sans SC 的扩充子集，包含属性、技能和出处文案；更名为 Armor UI Review R03，保留 OFL 和版权 |
| `preview.html` | 实际组件 + 真实文字重组的状态查看器，十个场景可切换；不是 Unity 或完整的游戏业务原型 |
| `preview-*-browser.png` | 本轮浏览器运行核验截图 |
| `text-bounds.json` | 原生绘制后的文字像素范围，用于检查三行技能说明、安全区和越界 |
| `image-hashes.json` | 本轮输出效果图的 SHA-256；重复构建检查依据 |
| `validation.json` | 实际素材、排版、数值 / 卡数 / 排序、浏览器与对照工具检查记录；Unity 项独立为未验证 |

节点坐标统一为 **1080 × 2340**。`base` 节点按 r02 的 830 × 1896 原生布局组装，再按 r02 的转换系数绘制。其他弹层节点直接使用 1080 画布坐标。底板、卡牌、文字、遮罩与弹层必须保持独立对象，不能把本轮 PNG 当游戏界面。

卡牌 ID 与 r02 `layout.json` 中的原卡表索引一致，从 0 起：例如 9 = 力天使，7 = 高达X，3 = 高达，0 = 飞弹齐射。`base.slots` 的前八项为出战卡、后六项为按费用排序的收藏卡；`hide` 仅隐藏正在选中 / 浮起的实例，其他独立节点补回该卡，不能复制出第二张卡。

## 接入要点

1. **S01a / S01b**：选中放大 1.08、青色光；收藏卡显示“使用 / 信息”，出战卡只显示“信息”。这两张选择的都是所在区第一行，因此气泡在下方并向上指向卡；后续其他行按需求可放上方。按钮的 `visualRect` 与 `hitRect` 分开，点击框不小于 88 × 88。
2. **S02**：力天使放大到 360 × 516，收藏与底栏压暗 60%。八张出战卡以同相位晃动 ±3°、0.4 秒一周期，青光呼吸；排序 / 筛选 / 底栏禁止响应。关闭按钮显示 72 × 72，点击框为 88 × 88。点空白取消，取消不得修改卡组。
3. **互换**：0.25 秒；入场曲线控制点 `[860,1320]`，回收藏曲线控制点 `[220,1050]`。开始 / 中途 / 结束三个节点已提供。力天使从浮卡到第八个出战槽，高达X回按费用排序后的收藏第 13 个实例槽（0 起索引 12）。结束必须维持八张互不重复的出战卡，平均费用 3.5、四卡循环 11，并显示“自定义”。
4. **S03**：主面板 `[60,360,960,1560]`，XL 卡 `[96,544,360,516]`。属性、技能、原作出处与按钮各自独立；使用 r02 比例而非旧版 360 × 444。更高的卡片不允许盖住技能区。战术版面板高 1320，去掉原作区，按钮上移。
5. 从收藏打开高达图先把高达换出到收藏，背景卡组也随之变化；从出战打开高达图使用原版卡组。来源决定按钮组：收藏为“使用 / 关闭”，出战为单个“关闭”。如果绑定真实业务卡组，就以实际来源为准，不复用错误按钮组。
6. 精神力样例三行说明用 28 px、45 px 行距，按 `text-bounds.json` 已能装下；勿通过自动缩字掩盖裁切。字体子集只供本轮还原，正式运行继续使用同字形 / 500、700 字重的完整字体。
7. r03 新面板 / 图标是参考交付，界面确认后再统一正式命名和尺寸。原有 r02 导入要求继续适用：Full Rect、PPU 100、Bilinear、sRGB、Compression None、无 Mipmap。材质 Image 用白色 tint；不要用默认圆角框或渐变替代实际装甲像素。

## 数据来源

高达：需求第 6 节。飞弹齐射：`DesignDocs/reports/REPORT-016.md`，伤害 240 / 范围 3 米 / 击晕 0.5 秒以及文案。精神力：`DesignDocs/tasks/TASK-018_精神力高达.md` 的初版参数，仅用于最长说明排布，不是实机数值变更任务。

## 打开与重建

从仓库根目录临时运行 `python -m http.server --bind 127.0.0.1`，打开本目录 `preview.html`。状态选择器只供设计核验，画布本身不接入游戏业务；策划端的可交互原型位于另一个 `prototype/` 目录。

重建：

```text
python tools/render_deck_armor_r03.py
```

## Unity 截图对照

默认不传参数时，对比脚本仍使用 r02 的 S01；本轮状态请明确传入目标参考图：

```text
python tools/compare_deck_armor.py unity-S01a.png --reference DesignDocs/ui/deck/mockups/r03/S01a_select_collection.png --out output/compare-S01a
python tools/compare_deck_armor.py unity-S03.png --reference DesignDocs/ui/deck/mockups/r03/S03_detail.png --out output/compare-S03
```

仅接受 1080 × 2340 的单屏参考图和 Unity 原始截图，不自动缩放 / 移位；三帧拼板不能作为实机单屏参考。输出 overlay / difference / 分区数值后，逐项核对面板、卡槽、基线、按钮、材质及动态状态。**没有 Unity 原始截图前，不把还原验收写成完成。**

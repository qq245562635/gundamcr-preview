## 关键实现约束

1. 所有可变文案和数字独立绘制，不烘焙到素材。V、S是固定装饰艺术字，独立纹理是有意设计，不能拿它们作可变语言文本。头像的 AI/指同样是文字层。
2. 板底为头像留透明孔，必须和对应 Badge 一起装配；板、头像和文字挂到同一父节点一起入场，不能各自不同步。
3. 加载框、底和填充分别导入。填充使用左侧起点的裁剪或 Unity Image Filled/Horizontal，不缩放外框；百分比在同一条右端独立显示。100%填充只覆盖实际填充槽，右边保留百分比区域。
4. V/S分别从左右进入；底图已去除静态飞溅火花。瞬态效果用 FX_Flash/FX_Streak 实例播放，1.25秒静态图不保留凝固火花。FX纹理为程序绘制，非从原稿无损提取。
5. 原始确认图是生成式合成图，无PSD源层。背景遮挡区、去文字材质由 imagegen 恢复，再进行轮廓遮罩和分层；不能声称逐像素无损。已提供确认图与重组图，视觉差异待本轮审查。
6. 卡框/卡图复用已定 armor-r02，沿用 PR #2 最新审图认可的定位色块方案；自由为已有缺图占位，战术图为通用示意，非官方素材。各图片 purpose 记录来源。字体使用完整 Noto Sans SC（本地字体，不打包系统字体）；不使用微软雅黑。
7. 以830×1895母图为坐标基准等比缩放至高2340，左右补深蓝窄边，未非等比拉伸。新L03坐标与旧线框不同，见layout；未修改策划正文或旧轮素材。
8. 导入：Sprite Single、FullRect、PPU100、Bilinear、sRGB、Compression None、MipMap Off。alpha透明；装甲素材保持白tint。FX可选Additive，预览用screen近似，Unity需校验色彩。

# L03 动效交付说明

## 层级与锚点

在1080×2340设计Canvas中，背景静止；所有矩形和文字位置见layout.json，左上为原点。Sprite pivot在slices.json，默认中心(0.5,0.5)；加载填充为左中(0,0.5)。V/S父组的缩放/震动原点使用layout.groupPivotPixels中的同一对阵中心，而不是全屏中心。

- OpponentRoot：OpponentPanel → OpponentBadge → 对手/AI/名字/卡组文字。
- PlayerRoot：PlayerPanel → PlayerBadge → 指/名字/卡组文字。
- VSRoot：VRoot、SRoot分别移动，但以共同视觉中心缩放；不得把名字或进度条挂在震动节点下。
- DeckRoot：DeckPanel；Card0…Card7各自为图窗、卡框、费用/名称文字的小组。子卡依次淡入时图和字必须同步。
- LoadingRoot：LoadingTrack + LoadingBed + LoadingFill + 提示/加载中/百分比文字。图片框为静态，只有填充裁剪范围改变。
- FXRoot：独立Flash、Streak实例，不与背景合并；位于VS附近上层，不能长期遮挡身份/卡牌/进度。

## 入场时间表（建议值；JSON与预览可审查）

| 时间 | 行为 |
|---|---|
| 0–0.34s | 对手组从左180设计像素进入，alpha0→1，cubicOut |
| 0.08–0.42s | 我方组从右180像素进入，alpha0→1，cubicOut |
| 0.25–0.55s | V从左360、S从右360进入，缩放1.15→1；0.49s撞击 |
| 0.49–0.65s | 单次Flash衰减；不循环闪屏 |
| 0.49–0.79s | 十个固定方向Streak短暂散开并淡出；后续Unity可用粒子池 |
| 0.49–0.61s | 仅V/S做最大4px快速衰减震动，文字与进度不震 |
| 0.55–0.85s | 卡组托盘上移24px并淡入 |
| 0.65s起 | 八卡间隔35ms，单卡220ms上移16px并淡入 |
| 0.60–0.85s | 提示与加载组件淡入 |
| 1.25s | 入场完全稳定，等待真实加载进度 |

以上动画可用Animator或DOTween等按项目现有方案接入；此包只提供资源、参考时序和审查器，没有安装运行时依赖。生成式背景为一个静态场景层，不适合直接拆红蓝两半飞入，以免暴露补绘边缘；主体对撞由信息板/V/S完成。

## 真实加载状态

`progress = clamp(actualLoadedWeight / totalWeight, 0, 1)`；必须由真实资源/场景就绪事件驱动，不能按动画计时自动涨到100%。显示 `floor(progress*100)`，填充来自同一个progress值。可做不超过80ms的追赶插值，但插值不得超过真实值；进度不能倒退。审查器滑杆只用于验证，不能作为生产加载逻辑。

只有场景与资源均ready时进入100%。建议至少显示100% 120ms，然后整组180ms淡出；正常情况下同时等待入场完成。用户选择跳过/减少动态时可立即展现稳定态，并跳过入场等待。网络或资源失败应由业务显示错误/重试，不把失败伪装为完成；这些业务状态本包未实现。

## 性能与可访问性

- FX仅一次触发，粒子复用，不在每帧新建纹理；动画仅改transform/alpha和fillAmount。
- 静态材质不要做每帧模糊；additive根据目标设备和色彩空间核验。
- 减少动态：取消位移、缩放、震动、闪光和粒子，直接进入稳定布局；保留真实进度更新。
- 暂停、重复入场和销毁时取消旧动画与FX，重置alpha/transform/clip，避免残留。审查器可任意seek，复现同一时间应得到相同画面。
- 9:16需另外布局/安全区验证；不把本竖屏整张拉伸当适配。
